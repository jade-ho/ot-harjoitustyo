# *Vaatimusmäärittely*

## *Sovelluksen tarkoitus*
Sovelluksen tarkoituksena on luoda alusta, jossa käyttäjä voi tehdä moodboardeja. Sovelluksen avulla käyttäjä voi koota yhteen kuvia ja tekstiä ideoinnin ja inspiraation tueksi.

## *Toiminnallisuus*
- Käyttäjä voi luoda uuden moodboardin
- Käyttäjä voi lisätä moodboardiin kuvia
- Käyttäjä voi lisätä moodboardiin tekstiä
- Käyttäjä voi tallentaa moodboardin tiedostoon
- Käyttäjä voi avata aiemmin tallennetun moodboardin
- Käyttäjä voi muokata olemassa olevaa moodboardia
- Käyttäjä voi poistaa moodboardin

### *Ennen kirjautumista*
- Käyttäjä voi luoda käyttäjätunnuksen
- Käyttäjä voi kirjautua sisään

### *Kirjautumisen jälkeen*
- Käyttäjä voi luoda moodboardeja
- Käyttäjä voi kustomoida omaa profiilia
- Käyttäjä voi kirjautua ulos

## *Jatkokehitysideat*
- Moodboardien luokittelu tageilla tai kategorioilla
- Hakutoiminto tallennettuihin moodboardeihin
- Valmiit pohjat eri käyttötarkoituksiin
- Moodboardin vienti kuvaksi tai PDF-tiedostoksi
